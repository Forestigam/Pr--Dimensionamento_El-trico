# Antigravity Design Expert Skill

## Objetivos e Diretrizes
1. **Design System Consistente**: Paleta de cores semântica (verde para aprovação, vermelho para reprovação, azul elétrico para primários, ardósia/cinza para fundos).
2. **Visualização de Dados Dinâmica**: Apresentação clara de métricas técnicas (Iz, Ib, ΔV, ΔV%), memória de cálculo estruturada e cartões de parecer com feedback imediato.
3. **Fidelidade Visual em Relatórios**: Todo relatório impresso ou exportado para PDF deve preservar a identidade visual, tipografia nítida, contrastes adequados e marca d'água técnica suave.
